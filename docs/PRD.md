# PRD — About Section Asset Replacement

**Project:** Existing Portfolio Website  
**Task:** About Section — Car Images & Browser Favicon Replacement  
**Scope:** Asset replacement only  
**Priority:** Strict — No UI/UX Changes

## 1. Objective

Update the existing About section using the owner's supplied assets from the existing project workflow folder named `My Images` (or its existing exact folder name).

Two tasks are required:

1. Replace the seven existing car images belonging to another person with the owner's seven supplied car photographs.
2. Replace the existing website favicon with the owner's supplied favicon.

## 2. Asset Source

Locate the existing `My Images` folder inside the project/workflow directory.

It contains:
- 7 personal car photographs.
- 1 custom favicon.

Use these exact assets.

Do not download, generate, or substitute any other images or icons.

## 3. Car Gallery Replacement

The existing About section contains seven car cards.

Requirements:

- Remove the previous owner's photographs.
- Insert the seven supplied photographs into the seven existing cards.
- Maintain the existing image sequence.
- Preserve the existing swipe interaction.
- Users must be able to navigate through all seven cars sequentially.
- Crop images appropriately to fit the existing image containers.
- Keep each car clearly visible.
- Never stretch or distort images.

Do not create additional cards.

Do not remove existing cards.

## 4. Favicon Replacement

Replace the existing browser favicon with the supplied custom favicon.

The favicon must appear in the browser tab when the website is opened in Chrome.

Requirements:
- Use the supplied favicon asset.
- Update the existing favicon reference correctly.
- Preserve the existing project structure.
- Ensure the favicon loads without a 404 error.
- Verify the favicon appears in the browser tab.

Do not create a new logo or substitute another icon.

## 5. Design Preservation

The existing portfolio design is locked.

Preserve:
- Existing UI and UX.
- Existing fonts.
- Existing colors.
- Existing card dimensions.
- Existing image containers.
- Existing spacing.
- Existing animations.
- Existing swipe functionality.
- Existing responsive behavior.
- Existing navigation.
- Existing save functionality.

Only the requested images and favicon may change.

## 6. Acceptance Criteria

- [ ] Seven old car photographs are replaced.
- [ ] Seven owner photographs are displayed.
- [ ] All seven cards remain functional.
- [ ] Swipe navigation works.
- [ ] Image cropping is correct.
- [ ] No image is distorted.
- [ ] Custom favicon is visible in Chrome's browser tab.
- [ ] No unrelated UI changes occur.
- [ ] Existing project functionality remains intact.
- [ ] Existing memory.md workflow is respected.

## 7. Completion Report

Report:
- Seven image filenames.
- Image display order.
- Crop adjustments.
- Favicon filename and format.
- Files modified.
- Swipe test results.
- Browser favicon verification.
- Build/test results.
- Memory update status.
